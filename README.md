# CheatSomething

**CheatSomething** is a helper application for the game *Draw Something*. It assists players by generating a list of possible word solutions based on the given set of letters, sorting them by word length to prioritize longer words.

## Features

- Input the available letters from your *Draw Something* game
- Generates a list of possible word matches
- Results are sorted by word length, helping you identify longer words for higher scores
- Simple and intuitive user interface

## Usage

1. Launch the CheatSomething app on your device.
2. Enter the letters provided in your *Draw Something* game into the app.
3. Browse through the list of possible word solutions generated.
4. Select the word that best fits the drawing or yields the highest points.

## Development

This project is developed in Objective-C and is structured as an Xcode project.  
It includes resources tailored for iPad, such as specific image assets and localization files.

### Project Structure

- `CheatSomething.xcodeproj/` – Xcode project files
- `CheatSomething/` – Main application source code
- `Resources-iPad/` – iPad-specific resources (images and localization)
- `wordlist.csv` – A CSV file containing the list of valid words used for matching
